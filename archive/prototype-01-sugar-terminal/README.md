# Mustafa World - Prototype 0

웹에서 실행되는 터미널 스타일의 Living Personal Space 프로토타입이다.

## 실행

브라우저에서 `index.html`을 열면 바로 실행된다.

## 현재 포함된 것

- 중앙 Terminal Window
- 로그 영역
- HP / MP / ST / LOC 상태바
- 입력창
- 입력 후보 추천 UI
- 집 내부 네 공간: 거실, 작업실, 침실, 베란다

## 기본 입력

- `둘러봐`
- `가 거실`
- `가 작업실`
- `가 침실`
- `가 베란다`
- `상태`
- `조용히 있어`
- `도움`

입력 후보는 `↑`, `↓`로 선택하고 `Tab`으로 입력창에 채울 수 있다.
