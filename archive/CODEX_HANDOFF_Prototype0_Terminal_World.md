# Codex Handoff - Prototype 0 (Terminal World)

## 프로젝트의 현재 성격

이 프로젝트는 MUD를 복원하는 프로젝트가 아니다.

또한 MMORPG를 만드는 프로젝트도 아니다.

현재 목표는 **살아있는 개인 공간(Living Personal Space)** 을 탐험하는
것이다.

출발점은 한국 MUD였지만 현재는 다음 세 흐름이 합쳐지고 있다.

-   한국 MUD
-   현대 AI CLI UX
-   Roguelike / TUI 인터페이스

최종 결과물이 게임인지 홈페이지인지 개인 위키인지는 아직 결정하지
않는다.

## 목표

이번 프로토타입은 제품이 아니라 탐사 장비다.

성공 조건은 다음 한 문장이다.

> 이유 없이 다시 접속하고 싶은 공간인가?

## Prototype 0

웹에서 실행되는 터미널 스타일 인터페이스를 만든다.

구현 대상

-   중앙 Terminal Window
-   로그 영역
-   상태바
-   입력창
-   입력 후보 추천 UI

게임 로직은 최소화한다.

## 입력 원칙

-   기본은 타이핑
-   AI CLI처럼 후보 추천 제공
-   GUI 버튼으로 대체하지 않는다.

예시

    > 쳐

    ▶ 고블린
      늑대
      오크

## Codex에게

Prototype 0은 제품이 아니라 연구 장비다.

빠르게 구조를 바꾸기 쉬운 설계를 우선한다.

## Version Log

### V1 - sugar terminal

보관 위치: `archive/prototype-01-sugar-terminal`

상태: 폐기.

사유: 사용자가 원한 것은 터미널을 닮은 웹 UI가 아니라 `ink`, `xterm.js` 계열의 실제 TUI 표면이었다. 장식형 JRPG 프레임과 DOM 기반 입력 UI는 방향이 맞지 않았다.

### Current direction

루트 앱은 `xterm.js` 기반으로 전환한다.

-   DOM으로 터미널처럼 보이는 UI를 만들지 않는다.
-   xterm.js 터미널 버퍼 위에 ANSI 출력으로 화면을 그린다.
-   로그, 상태, 프롬프트, 후보 추천은 모두 터미널 내부 출력으로 취급한다.
-   톤은 더 건조하게 유지한다.

상세 UI 설계는 `docs/DESIGN.md`의 `UI 설계` 항목을 따른다.
