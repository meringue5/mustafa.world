# UI Design

이 문서는 xterm 레이아웃, 폰트, 색, 입력 패널, 스크롤, 한글 입력 경계 처리를 담는다.

현재 세부 설계의 상당 부분은 아직 `../DESIGN.md`에 남아 있다.

중요한 현재 결정:

-   터미널 내부 UI는 ANSI/xterm 출력이다. DOM 위젯이 아니다.
-   하단 입력 패널은 5줄 고정이다.
-   입력줄에는 보이는 `>` 프롬프트를 두지 않는다.
-   후보 선택은 괄호 문자가 아니라 ANSI 반전색으로 표시한다.
-   터미널 폰트는 `IyagiGGCHalf`다.
-   기본 데스크톱 터미널 지오메트리는 `132 x 50`이다.
-   작은 viewport에서는 모바일/소형 창 대응 profile인 `80 x 40`을 사용한다.
-   브라우저 화면 전체에 터미널을 맞추지 않는다. 중앙에 고정된 profile 크기의 터미널 화면을 배치하고, 주변 영역은 향후 DOS풍 그래픽/픽셀아트 레이어를 위한 빈 무대로 둔다.
-   데스크톱에서는 132x50 논리를 유지한 채 화면 여유가 있으면 최대 `1.2`배까지 확대한다.
-   모바일에서는 `visualViewport` 기준으로 보이는 viewport 높이를 따라가며, 가상 키보드가 열린 상태에서도 terminal frame을 보이는 영역 안에서 다시 scale한다.
-   xterm 자체 viewport 스크롤바는 숨긴다. 본문 스크롤은 앱 내부 라인 단위 스크롤로 처리한다.
-   후보 선택 터치는 DOM 버튼이 아니라 xterm screen 좌표를 터미널 행/열로 변환해서 처리한다.
-   모바일 터치 기본 동작은 페이지 스크롤, 텍스트 선택, 더블탭 확대가 터미널 조작을 방해하지 않는 범위에서 억제한다.
-   한글 IME 조합 중인 글자를 미리 추적하지 않는다.
-   후보 추천은 확정된 입력이 공백으로 끝나는 단어 경계에서만 열린다.
