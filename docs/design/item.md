# Item Design

이 문서는 사물, 아이템, 인벤토리, 상호작용 설계를 담는다.

현재 세부 설계의 상당 부분은 아직 `../DESIGN.md`에 남아 있다.

중요한 현재 결정:

-   사물은 장소 설명 안에 자연스럽게 언급되고 하이라이트될 수 있다.
-   아이템 affordance는 `edible`, `portable`, `giftable` 같은 명시적 태그에서 나와야 한다.
-   아이템은 텍스트 예측이 아니라 세계 상태 기반 affordance를 통해 후보에 참여한다.
-   `aliases`는 같은 대상을 부르는 다른 이름만 담는다.
-   포함물, 부품, 위에 놓인 물건은 alias가 아니라 별도 사물로 분리한다. 예를 들어 `책장`의 alias에 `책`을 넣지 않고, `책장`과 `책`을 각각 object로 둔다.
-   사용자가 직접 입력할 수 있어야 하는 명사는 현재 장소, 인벤토리, 행위자 중 하나의 명시적 엔티티여야 한다.
